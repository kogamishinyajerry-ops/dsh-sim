# buffer_chamber 能力包使用说明（SKILL）

> 版本 0.1.0 · 状态 DRAFT · 未经 Owner 发布不得用于正式任务。
> 依据：定义书 §能力包与最小知识体系、§指标定义、§数值、方法与工程接受的门。

## 何时使用

仅当任务**同时**满足以下条件时，才可考虑使用本能力包：

1. 任务族为 STAR-CCM+ 缓冲腔 CFD：稳态、单相、内流，物理组合与本包 `domain.json` 一致。
2. 用途为 `design_screening`（内部方案筛选），不是适航符合性结论。
3. 几何来自已登记的 1—2 个 .sim 模板（templates/ 中有哈希登记），工况为批准工况表内的 1—3 组。
4. 本包状态为 **RELEASED** 且兼容清单（DSH 版本 / STAR-CCM+ 构建）与当前环境匹配（FR-27：版本不在兼容清单时禁止真实运行）。

当前 0.1.0 为 DRAFT 且兼容清单全部 UNCONFIRMED，因此**当前任何正式任务都不得使用本包**；仅可用于协议开发与 Mock 联调。

## 怎么解释

- 指标口径以 `metric-definitions.json` 为准：边界质量流量（向外为正）、稳态质量不平衡（m_floor 保护分母）、总压损失（批准截面质量流量加权）、出口分配（f_i = m_i / Σ_out）、A/B 变化（B−A，参考下限内只报绝对差）、监控稳定性（批准窗口）。
- 比较必须同口径：同工况、同截面、同总/静压定义、同算法版本；定义不一致时**禁止给出改进幅度**。
- 数值状态四态 NOT_CHECKED / PASS / FAIL / INSUFFICIENT：程序成功 ≠ PASS；缺值为 null 并标缺失，不填 0、不估算。
- 适用性三态 IN_SCOPE / OUT_OF_SCOPE / UNCONFIRMED：数值 PASS 不证明物理方法适用。
- 所有工程阈值（容差、窗口、m_floor、参考下限、网格要求）当前为 null/TBD：这意味着本包**尚不能对任何数值下"通过"结论**。

## 何时停止（命中任一即停，不绕行）

1. **范围外停**：构型、工况、物理组合或用途任一项超出已 CONFIRMED 范围，或适用性为 OUT_OF_SCOPE → 拒绝正式求解并说明原因（FR-03）。
2. **UNCONFIRMED 停**：适用范围、边界映射、模板/宏哈希、兼容版本任一项为 UNCONFIRMED → 停在 UNCONFIRMED，不沿用原结论、不猜测映射（TBD-04/TBD-05，P04 未过不准备）。
3. **回读不一致停**：写入被忽略、旧缓存、边界身份错误或申请/回读存在差异 → 停在 PREPARING，差异未清除时运行按钮禁用（FR-07；ADR-06 真实回读先于人工确认）。
4. **阈值未冻结停**：任何发布检查发现阈值仍为 null/TBD → 拒绝 RELEASED；运行中不得由模型或开发临时填值。
5. **证据不足停**：缺 CSV、缺回读、缺独立参考 → 标 INSUFFICIENT，不把部分通过归为整单通过。
6. **权限停**：Agent 不得取得人工运行确认与审查接受权限；不得代点确认、代签接受。
