# templates/ — 受控 .sim 模板引用登记

本目录**只存放受控 .sim 模板的引用登记**（JSON 引用记录），**不打包商业软件安装包、不打包真实 .sim 工程文件**（定义书 §能力包与最小知识体系："受控.sim引用，不把商业安装包打入"；§离线、部署、备份与运维："不打包商业软件或用户许可证"）。

## 登记规则

每个模板一个 `<template_id>.ref.json`，字段要求：

| 字段 | 说明 |
|---|---|
| `template_id` | 稳定标识，TaskSpec `variants[].template_ref` 引用此值 |
| `sha256` | 模板文件内容哈希（canonical-json-v1 体系外的文件级 SHA-256） |
| `source` | 模板来源（哪个受控文件目录/谁准备的） |
| `registered_by` / `registered_at` | 登记者与时间 |
| `star_ccm_build` | 制备该模板的真实软件构建号（当前一律 `UNCONFIRMED`，待 P01/P02 探针采集） |
| `approval_ref` | 指向 approval.json 中批准该模板进入本能力包的记录 |

## 铁律

- 同名不同文件不能当作同一输入（FR-02）：身份 = 内容哈希，不是文件名。
- 未经批准的新文件不得直接成为方法模板（定义书 §输入契约与摘要规则 variants 字段组）。
- 模板原件哈希在准备作业中必须保持不变（FR-06）；任何副本写入只发生在 Worker 工作副本上。
- 当前目录为空：首版 A/B 两套可比较模板属启动假设输入（定义书 §启动假设），尚未登记。
