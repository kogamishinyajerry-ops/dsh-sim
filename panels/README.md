# dsh-sim · panels/（Agent F / WP-12 执行台 + WP-15 审查台）

原生 ES Module 静态页面，无框架无构建。FastAPI 静态挂载于 `/panels/executor/` 与 `/panels/reviewer/`，
fetch 目标为工程 API（默认 `http://127.0.0.1:8600/api/v1`，可用 `?api=` 查询参数或
localStorage `dshsim.api_base` 覆盖）。

## 状态徽章字典（英文枚举原文 + 中文注释，颜色不是唯一表达）

| 维度 | 枚举 → 中文 | 样式 |
|---|---|---|
| TaskFlow | DRAFT 草稿 / PREPARING 准备中 / READY 待确认 / AUTHORIZED 已授权 / ACTIVE 执行中 / READY_FOR_REVIEW 待审查 / IN_REVIEW 审查中 / ACCEPTED 已接受 / CHANGES_REQUESTED 已退回 / REJECTED 已拒绝 | 灰/蓝/实心蓝/琥珀/绿/琥珀/红 |
| Execution | QUEUED 排队中 / WAITING_RESOURCE 等待资源 / LEASED 已领取 / STARTING 启动中 / RUNNING 运行中 / CANCELLING 取消中 / COLLECTING 收集产物 / SUCCEEDED 执行完成(≠数值通过) / FAILED 执行失败 / CANCELLED 已取消 / **LOST 失联(状态未知)** | LOST=红色条纹底+粗体 |
| Numerical | NOT_CHECKED 未检查(灰虚线) / PASS 数值通过(绿) / FAIL 数值失败(红) / INSUFFICIENT 证据不足(琥珀) | — |
| Applicability | IN_SCOPE 范围内(绿) / OUT_OF_SCOPE 范围外(红) / UNCONFIRMED 范围未确认(琥珀) | — |
| Review | NOT_SUBMITTED 未提交(灰虚线) / PENDING 待审(琥珀) / CHANGES_REQUESTED / ACCEPTED / REJECTED | — |
| Validity | CURRENT 当前有效(绿) / STALE 已过期(红) | — |
| evidence_mode | REAL 真实(绿) / **MOCK 模拟数据(琥珀+斜体水印)** / UNKNOWN 状态未知(条纹底) | 顶栏常驻 |
| 通用 | NOT_RUN 未执行（灰色虚线徽章） | — |

纪律：绝不用一个绿勾代替多维判断；SUCCEEDED 徽章文字明确标注"≠数值通过"。

## 降级行为说明

| 情形 | 面板行为 |
|---|---|
| API 离线（网络失败/超时） | `api.js` 返回 `{offline:true}` 不抛死；顶栏 evidence_mode 强制 UNKNOWN；页顶插入"工程服务不可用"条纹横幅；所有写操作（确认运行/取消/回复/关闭/决定）禁用；各区域显示降级说明而非空白。 |
| API 返回错误对象 | 渲染 `{code,message,retryable,trace_id}` 错误块 + trace_id 复制按钮；区域级降级，不影响其他区域。 |
| openapi.v0.1 未定义的读取端点（GET /tasks、revisions/latest、runs、bundles/latest、claims、metrics、verifications 等） | 404/未就绪 → 对应区域显示"接口未就绪（NOT_RUN）"降级文案；执行台支持手工输入 task_id，审查台手工输入 review_id。 |
| MOCK 模式 | 顶栏琥珀徽章 + 斜体 MOCK 水印；审查台把 MOCK 证据计入阻塞清单，接受按钮禁用。 |
| NOT_RUN | 无 Run 的矩阵格、无准备数据、无证据包、无复算记录统一用灰色虚线徽章 + 文字"未执行/未就绪"，不猜色。 |
| 心跳 >45s（15s×3） | 运行区域显示失联条纹告警；execution_state=LOST 时整卡醒目横幅。 |

## 与 DSH 原生槽位的关系

当前实现是定义书 §锁版接入方式允许的**"受保护审查页"临时实现**：
DSH 0.1.5 sidebar/main 面板槽位与 cookie 隔离未经锁版兼容探针（TBD-01）证实前，
两张面板由 FastAPI 静态挂载、从 DSH 对话中以受保护页面方式打开，作为同一任务入口。

- **期限**：本降级实现仅覆盖 R0 试用阶段；WP-11 锁版兼容探针通过前不得宣称已嵌入 DSH 原生槽位。
- **升级路径**：槽位与 cookie 隔离可证明后，将同一组 ES Module 页面注册为 DSH sidebar 面板
  （页面不依赖任何宿主私有 API，仅需替换加载入口与身份注入方式——dev 头换成受信会话凭据）。
- 人工确认/接受凭据（confirmation_id）只能由受信 UI 会话发起消费；不得交给 DSH 工具进程或模型。

## 打印

打印样式保留任务/Run/issue ID 与全部摘要：digest 短码在打印时展开为全量（title 内容），
链接附带 URL，徽章转为黑框文字，不依赖颜色。

## monitor/ 仿真监控台（只读实况）

同事在 DSH 插件点"监控"页签即达 `/panels/monitor/index.html`。无侧栏单列布局，
聚合**所有任务**的运行中 Run（executor 只看单任务，monitor 看全局）。

### 数据依赖

- `GET /tasks` → 全量任务；逐任务 `GET /tasks/{task_id}/runs`（**runs 投影含 events 数组**：
  `event_seq / kind / payload / occurred_at`），并行拉取、逐任务降级。
- HEARTBEAT `payload` 宽松提取：`stage`、`log_path|log_location`、
  `residuals|history|residual_history`（或单值 `residual`）数组 → 残差序列。
- 心跳判定与 executor 一致：最后 HEARTBEAT（无则退回最后事件）距今 >45s（15s×3）
  → 失联条纹告警。
- 事件 kind：STARTING / RUNNING / HEARTBEAT / COMPLETED / FAILED / CANCELLED，
  超出集合按 UNKNOWN 条纹徽章渲染，不猜色。

### 降级行为

| 情形 | 面板行为 |
|---|---|
| 残差流缺失（payload 无 residuals/history） | 显示"暂无残差流（该作业类型未上报）"或"仅 1 个采样点，不足以绘图"；**不画假数据** |
| stage / 日志位置字段缺失 | 显示"阶段：无数据"/"日志位置：（未上报）"，不留空白 |
| run 无 events 数组 | 事件时间线区显示"无事件数据（该 run 尚未上报 events）" |
| 单任务 /runs 读取失败 | 该任务区域降级 + 错误说明；保留上一轮缓存卡并注明"可能过期，以时间戳为准"；不影响其他任务 |
| /tasks 接口错误（非离线） | 主区域显示"任务列表接口未就绪"+ 错误块（含 trace_id） |
| 服务离线 | offline 横幅 + 空态卡片 + 服务状态 OFFLINE 徽章；evidence_mode 强制 UNKNOWN；每 3s 自动重试 |
| evidence_mode 混合 | 多个 run 上报不同 mode → 按 MOCK 保守呈现（琥珀徽章 + 水印） |

### 轮询策略

- 固定 **3s** 间隔（监控页比执行台的 4-6s 抖动更快）；
- `document.hidden` 时跳过本轮请求（仅刷新"已暂停"状态行），回到页面立即补一次拉取；
- 上一次请求未返回时跳过本轮（防重入叠帧）。

### 技术约束落实

- 原生 ES Module，零外部 CDN：sparkline 为手写 SVG（polyline + 末值圆点/标注），
  y 轴 `log10(max(|x|,1e-30))`，viewBox `0 0 300 64` 自适应、容器 100%×64px。
- 失败/取消 run 用红/灰左边框卡呈现历史，不修改、不隐藏。
- 打印样式：保留 run 短 id（展开全量 title）、状态摘要、sparkline 边框。
